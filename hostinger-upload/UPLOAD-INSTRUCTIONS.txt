WHY A SUBFOLDER (not the root)?
-------------------------------
Your ROOT  purffle.com  is already your main Purffle brand site
("One Brand, Many Worlds"). We must NOT overwrite that. So Claude
Multi lives at  purffle.com/claude-multi/  — every link, canonical,
sitemap and image in these files is set for that path.


WHAT TO UPLOAD
--------------
Upload the ENTIRE CONTENTS of this folder into:

    public_html/claude-multi/

(You already created that folder — good. Just replace its contents
with these corrected files.)

Files that must end up in public_html/claude-multi/:
  index.html
  404.html
  robots.txt          (see note below)
  sitemap.xml
  site.webmanifest
  .htaccess           <-- hidden file, don't miss it
  icon.png
  screenshot-*.png / .webp   (9 pairs)


STEPS (Hostinger File Manager)
------------------------------
1.  hPanel -> File Manager -> open  public_html/claude-multi/
2.  Select the OLD files already in there and DELETE them
    (so nothing stale is left behind).
3.  Click Upload -> choose ALL files from this folder.
       - To include the hidden .htaccess: click the ⚙ (Settings)
         top-right in File Manager and enable "Show hidden files",
         then upload it too.
4.  Confirm  index.html  is at  public_html/claude-multi/index.html


IMPORTANT — robots.txt
----------------------
robots.txt ONLY works at the domain root. This file's robots.txt is
just a reference. The REAL one must live at:

    public_html/robots.txt        ->  https://purffle.com/robots.txt

If you already have a robots.txt at your root, just make sure it
contains this line (add it if missing):

    Sitemap: https://purffle.com/claude-multi/sitemap.xml

(You do NOT need to put robots.txt inside the claude-multi folder.)


AFTER UPLOADING — GET RANKED
----------------------------
1.  Hard-refresh the page:  Ctrl+F5  (or open in Incognito). Browser
    cache is usually why "nothing looks different."
2.  Google Search Console (search.google.com/search-console):
       - Property for purffle.com should already exist.
       - URL Inspection ->  https://purffle.com/claude-multi/
         ->  "Request Indexing".
       - Submit sitemap:  https://purffle.com/claude-multi/sitemap.xml
3.  Test rich results:  https://search.google.com/test/rich-results
       Paste  https://purffle.com/claude-multi/  -> should detect
       SoftwareApplication, FAQ, HowTo, Breadcrumb, WebSite.
4.  Speed check:  https://pagespeed.web.dev/


That's it — static site, no PHP/database needed.
