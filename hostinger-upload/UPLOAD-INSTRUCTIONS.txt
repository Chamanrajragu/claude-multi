WHAT TO UPLOAD
--------------
Upload the ENTIRE CONTENTS of this "hostinger-upload" folder
(NOT the folder itself) into Hostinger's  public_html  directory.

Files that must end up in public_html/:
  index.html
  404.html
  robots.txt
  sitemap.xml
  site.webmanifest
  .htaccess          <-- IMPORTANT: it's a hidden file, don't miss it
  icon.png
  screenshot-*.png / .webp   (all of them)


HOW TO UPLOAD (Hostinger hPanel — easiest)
------------------------------------------
1.  Log in to Hostinger  ->  hPanel.
2.  Open  "File Manager"  (under Files).
3.  Go into the  public_html  folder.
4.  DELETE the old placeholder (e.g. default.php / index.html) if present.
5.  Click  "Upload"  (top-right)  ->  select ALL files inside this folder.
        - To include the hidden .htaccess:
          In File Manager, click the gear/⚙ (Settings) -> tick
          "Show hidden files (dotfiles)"  BEFORE uploading, OR just
          upload .htaccess separately.
6.  Make sure everything sits directly in public_html/ (not in a
    sub-folder). index.html must be at  public_html/index.html.

  (Alternative: use FTP with FileZilla — host = your domain, the
   credentials are in hPanel -> Files -> FTP Accounts. Drop all files
   into /public_html/.)


AFTER UPLOADING — DO THESE 3 THINGS FOR #1 RANKING
--------------------------------------------------
1.  SSL: hPanel -> Security -> SSL. Make sure an SSL certificate is
    ACTIVE for purffle.com (Hostinger gives a free one). The .htaccess
    already forces https, so SSL must be on or the site won't load.

2.  Google Search Console  (https://search.google.com/search-console):
      - Add property:  purffle.com  (Domain property).
      - Verify (Hostinger -> DNS, add the TXT record Google gives you).
      - Submit sitemap:  https://purffle.com/sitemap.xml
      - Use "URL Inspection" on  https://purffle.com/  ->  "Request
        Indexing".  This gets you crawled in DAYS instead of weeks.

3.  Bing Webmaster Tools (https://www.bing.com/webmasters):
      - Add site, import from Google Search Console (1 click),
        submit the same sitemap. (Bing also powers ChatGPT search.)


OPTIONAL BUT RECOMMENDED
------------------------
- Test rich results:  https://search.google.com/test/rich-results
  Paste  https://purffle.com/  -> should detect FAQ, HowTo,
  SoftwareApplication, Breadcrumb.
- Test speed:  https://pagespeed.web.dev/  -> paste your URL.
- Prefer www?  Open .htaccess and swap the www redirect block
  (comment says which lines).
